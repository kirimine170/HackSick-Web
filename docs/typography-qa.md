# 改行・アニメーションの表示確認

2026-11-02，公開preview向けの修正．

## 修正した原因

- Contactの狭い見出し列に，画面全体の幅を基準にした大きな文字が入っていた．見出し自身の列幅を基準にする．
- hoverでpaddingを変えると，メールアドレスや説明文の使える幅も変わっていた．hoverでは色を変更し，文字の配置と幅を維持する．
- PageHeroのnowrap指定が長いタイトルを画面外へ押し出していた．自然な折り返しを許可し，個人情報ページには意味に沿った行区切りを指定する．
- 日本語の複数行見出しに，文字サイズ未満の行高が使われていた．行高を確保し，各行の長さをbalanceで調整する．
- Creatorカードの画像列と余白が，名前と本文の幅を圧迫していた．画像列の比率と最小幅を見直す．
- 文字拡大時には，Gridの固定最小幅や長い英字・メールアドレスが原因で，フッター，News，開催情報，実績にもはみ出しがあった．列の折り返しと長い文字列の折り返しを許可する．

## JavaScriptによる演出

`src/scripts/reveal.ts`でIntersectionObserverとWeb Animations APIを使用する．フォント読み込み後に，まだ画面より下にある対象を観測する．初めから表示されている本文はフェードアウトさせない．画面へ入った要素は一度だけ再生し，opacityとtranslateだけを動かす．

スクロール位置を戻しても再生し直さない．フォーカス・pointerover時には演出を解除し，操作する内容をすぐ表示する．prefers-reduced-motionは変更時にも反映する．JavaScriptが無効な場合も本文は初めから表示される．

## 確認結果

Chromiumで，ビルド済みの静的HTMLと実際の配信フォントを使用した．Safari・Firefoxでの実行は今回の確認範囲外．

- 全34ページ（404を含む，旧Creator URLの転送ページを除く）を，320，360，375，390，414，540，700，768，800，980，1024，1180，1280，1440，1600，1920，2560pxで確認．578通りで本文のはみ出し，見出しの領域超過，見出し・ボタンに1〜2文字だけ残る行を検出しなかった．
- 全34ページで文字サイズを200％にし，375，768，1440pxの102通りを追加確認．本文のはみ出しと見出しの領域超過を検出しなかった．
- Contactの3リンクとトップのExplore 5リンクを，320，375，768，1024，1440，1920pxでhover．48件ともhover前後の幅，高さ，padding，テキスト領域が一致した．
- JavaScript無効時のトップ，Contact，Privacy，Creatorsで，本文の表示とはみ出しがないことを確認した．
- フォントの取得を一時保留し，代替フォントと配信フォントの両方で，トップの本文が切れず表示されることを確認した．
- 演出の初回再生，再訪時の非再生，フォーカス・hoverでの解除，動きを減らす設定の途中変更と初期適用を確認した．
- `npm run check`，`npm run build`，`npm run check:images`，`npm run check:links`，`npm run check:copy`が成功した．

## 今後の確認方法

フォント読み込みと，画面幅変更後の2フレームを待ってから測定する．実際の文字の行位置をRangeで取得し，見出しの幅と比較する．テキストが短い行だけ残っている場合は，画像でも判断する．カルーセルの非表示スライドや装飾のように，意図して画面外へ配置するものは本文のはみ出し判定から除く．

新しい長いタイトルは，PageHeroの`titleLines`で意味に沿う区切りを指定できる．その場合もnowrapで固定せず，狭い画面や文字拡大時の追加の折り返しを許可する．文字を計測して強制的に縮小するJavaScriptは使用していない．
