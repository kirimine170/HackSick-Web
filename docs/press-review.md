- 2026年10月30日に霧峰氏が陳列写真を撮影．撮影・掲載について当日に店舗から口頭許可を得たことを，運営本人が2026-11-02に確認した．クレジットは「撮影：霧峰／2026年10月30日」．書影のクレジットと陳列写真の撮影者を混同しない．
- 陳列写真は元の構図を残し，周囲を三角形のモザイクで表示する．`MosaicPhoto`を共通部品とし，必要に応じて六角形にも切り替えられる．元画像の各領域の平均色を幾何学形状へ割り当て，本作部分には元画像の画素を戻す．絵・文字を描き直した画像は使用しない．JavaScript無効時は，元写真の周囲をぼかした表示に本作部分を鮮明に重ねる．加工は表示上の処理であり，配信画像ファイル自体は元の構図を含む．陳列写真は1点，480・800pxのレスポンシブ版を使用し，ダウンロード資料には含めない．
- HSAP欄は運営の指示により予定を削除し，今回実施した作品紹介・プレス記事・書影とプロフィールの整備を実績として記載する．取扱店との交渉・契約，写真作品の共同制作が完了したとは記載しない．

- OGPは3ページ別に1200×630pxで作成し，原書影を描き直したり，縦横比を変えたりせず配置する．`node scripts/generate-book-media.mjs`で再生成できる．価格を変更した場合はOGPも再生成する．
- 解析の導入手順は`docs/analytics-setup.md`．計測タグの追加や外部サービスへのデータ送信は今回実施していない．

## 公開前確認

`npm run check:press -- --preview`は公開preview向け，`npm run check:press -- --production`は本番想定ビルド向けの確認．本番確認では，ビルド環境を`CF_PAGES_BRANCH=main`としてから実行する．公開先での200応答は，本番へデプロイした後にも確認する．previewのnoindexを外す目的では使用しない．
